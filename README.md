# ikukamo-now

「今すぐ行ける」を全国で宽く探すお出かけ候補アプリ。
ikukamo の既存コードは触っていない。

公開: https://github.com/longchanp7-hub/ikukamo-now

## 起動
```bash
git clone https://github.com/longchanp7-hub/ikukamo-now.git
cd ikukamo-now
npm install
npm run dev
```
http://localhost:3000
